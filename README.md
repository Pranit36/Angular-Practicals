## Practicals Included

### Practical 01 - Angular Basic Setup
Basic Angular project setup and application structure.

### Practical 02 - Angular Application
Basic Angular application implementation.

### Practical 03 - String Interpolation
Demonstration of Angular string interpolation using:
- Variables
- Expressions
- Method calls
- DatePipe

### Practical 04 - Student List
Displaying a list of students using Angular iteration.

### Practical 05 - Time Table
Creating a weekly time table using one-way data binding.

### Practical 06 - Student Portfolio
Creating a student portfolio using:
- Interpolation
- Property binding
- Lists
- Projects
- Contact information

### Practical 07 - Two-Way Data Binding
Demonstration of two-way data binding using `[(ngModel)]`.

### Practical 08 - Simple Routing Demo
Demonstration of Angular routing using:
- Home
- About
- Contact
- `routerLink`
- `routerLinkActive`
- `router-outlet`
